# DPH Archive OS · 风格规范

> 由 `tokens/tokens.json` 单一来源生成，供人类阅读的版本。任何数值修改请改 JSON 后运行 `python pipeline/build.py`。

## 1. 一句话定义

**技术档案 / OS 标本页**：温白纸面、零圆角、发丝线网格、三字母代码块、微型双语注脚，配一个面积不到 2% 的强调色。

## 2. 结构

```
┌ 顶栏 56px ── 品牌锁排 │ 面包屑 │ 版本·时钟·明暗 ─────────────┐
├ 左栏 216px ┬ 主栏（内容） ─────────────┬ 右栏 300px ────────┤
│ 栏目代码导航 │ 页头：编号 / 标题 / 说明 / 黑牌 │ 标本构造图      │
│             │ 内容：表格 / 卡片 / 色板     │ PROFILE / STATUS  │
│ 页脚微文案   │ 页脚注记带（贴底）           │                    │
├ 底栏 30px ── 编号 │ 品牌 │ 刻度 │ 页码 ──────────────────────┤
```

断点（容器查询，跟随面板实际宽度而非视口）：

| 容器宽度 | 行为 |
|---|---|
| > 1080px | 三栏 |
| 820–1080px | 隐藏右栏 |
| < 820px | 单栏，导航转为横向标签条，隐藏大号编号与次要标签 |

## 3. 颜色

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `bg-paper` | `#E7E4DF` | `#0A0A0B` | 纸面（主背景） |
| `bg-raised` | `#F6F4F0` | `#141414` | 卡片/悬停 |
| `bg-invert` | `#0B0F0D` | `#F1EEE9` | 黑牌、选中行 |
| `fg-primary` | `#0B0F0D` | `#E9E5DF` | 正文 |
| `fg-muted` | `#5B605B` | `rgba(233,229,223,.52)` | 微型标签 |
| `accent` | `#FF7500` | `#FF8A34` | DPH 品牌橙（图形） |
| `accent-text` | `#A34700` | `#FFA766` | 纸面上的橙色文字/标记 |
| `accent-invert` | `#FF7500` | `#B24A00` | 反白面上的橙色标记 |
| `system` / `system-text` | `#2971B8` / `#1F5C99` | `#6FA3D6` / `#8FBCE8` | 编号、序列号 |
| `alert` | `#B62A1E` | `#F2654F` | 印章、警示 |

规则：

- 强调色面积 **≤ 2%**；纸面上的橙色小标记一律用 `accent-text`，保证 4.79:1。
- 所有文字对比度 ≥ 4.5:1（正文 ≥ 7:1），见 `checks/checks.json`。
- 标识内部的 6px 橙色方点属 logotype，按 WCAG 1.4.11 豁免。

## 4. 字体

| 角色 | 字号 | 字重 | 字距 | 说明 |
|---|---|---|---|---|
| 巨型标题 | 44px | 800 | −0.035em | 栏目名，全大写 |
| 次标题 | 27px | 800 | 0 | 黑牌数字 |
| 小标题 | 18px | 700 | 0 | 卡片标题 |
| 正文 | 14px | 400 | 0 | 行高 1.5 |
| 密集行 | 12px | 400 | 0 | 表格 |
| 微型 | 9px | 700 | +0.14em | 全大写标签、序列号、注脚 |

- 中文与英文**同时出现**：主行为当前语言，次行为另一语言，字号差 2–3px。
- 数字一律等宽并启用 `tabular-nums`（时钟）。

## 5. 形状与质感

- 圆角：`0`（默认）/ `2px`（代码块）/ `999px`（状态点）。**不存在其他圆角。**
- 线：`1px` 发丝线；强调分隔用 `rule-strong`（32% 墨）。
- 阴影：仅卡片与黑牌使用 `--dph-elev-sheet`（浅色）或 `none`（深色，靠线区分）。
- 质感：32px 网格（5% 墨）+ 噪点（`feTurbulence`，透明度 4.5%）。

## 6. 组件规则

**页头黑牌**：32×24 视觉重量的黑块，含两位编号（30px/800）与栏目代码（8px mono），整体旋转 −1.6°，左侧 3px 橙色竖条。

**代码块**：`min-width 40px`、`height 20px`、黑色底、白色 9px/800 字、字距 +0.08em、2px 圆角。在反白行内自动反色。

**表格行**：11px 上下内距、1px 分隔线、悬停整行提亮并在左侧出现 2px 橙标记。

**注记带**：三列等分，`1px` 间隙以 `rule` 色透出形成分隔；每列「9px 全大写标签 + 9px mono 说明」。

## 7. 文案语气

- 名词短语 + 状态词：`ARCHIVE INDEX`、`TOOL REGISTRY`、`ALL SYSTEMS NOMINAL`、`LINK ACTIVE`。
- 不用完整句子做标签；说明句只出现在导语与注记里。
- 中英并置，不逐字直译，各自可读。

## 8. 禁用

- 不使用原作任何帧、标识、角色、字体、专有名词。
- 不引入第二个强调色；蓝色只用于编号/序列，不作为按钮色。
- 不增加圆角、渐变按钮、玻璃拟态——它们会破坏「档案纸」的材质逻辑。
