## 2. 九维风格要素

每条结论后为证据帧与置信度（高＝≥3 帧一致且跨界面类型；中＝2 帧；低＝单帧推断）。

### 2.1 布局

- **单栏海报式构图 + 一条竖向导线**：`ui_t144.png` 中 x≈390/1920（20.3%）处有一条贯穿全高的 1px 竖线，左侧放品牌块与微型列表，右侧放叠层卡片。整套版式贴合可见网格（地台镜头网格约 32–56px 一格，随透视变化）。**置信度：高**
- **信息主轴左对齐**，右半区留给「物」（人物、装置、卡片），左侧永远是可读的文本栏。**置信度：高**
- **卡片不居中、可出画**：`ui_t070.png` 右缘的巨大化字体被画框裁切，说明构图允许出血。**置信度：中**

### 2.2 色彩

以 k-means（k=7）对代表帧量化，并转 OKLCH：

| 角色 | 值 | 占比 | OKLCH |
|---|---|---|---|
| 纸（主背景） | `#E6E4E0` | 53.3% | `0.919 0.006 85` |
| 纸（暗部） | `#D5D0C8` | 15.3% | `0.859 0.012 80` |
| 白卡 | `#F4F5F2` | 19.7% | `0.969 0.004 122` |
| 墨（近黑，微绿偏） | `#0F1311` | 7.2% | `0.182 0.007 164` |
| 强调橙 | `#F77304` | **0.16%** | `0.702 0.187 49` |
| 暗场底 | `#000000` | 65.0% | — |
| 暗场暖橙 | `#B16B3E` / `#E07625` | 4.2% / — | `0.596 0.108 52` |

- 纸不是纯白：`#E6E4E0` 带极轻暖灰，且**通篇有纸张颗粒与噪点**。**置信度：高**
- 强调色面积极小（≈0.16%），只用于「当前对象/信号」：选中的部门砖、环形 logo、状态点、警示条。**置信度：高**
- 黑不是纯黑（`#0F1311`），暗场段落才用 `#000`。**置信度：高**

### 2.3 字体

- 三层字阶，对比极端：
  1. **巨型粗黑大写**（部门代码 CMPT/STRU/BSN，画面高约 6–9%）；
  2. **正文小字**（12–16px @1080p，用于名称条与说明）；
  3. **微型全大写**（约 5–7px，字距 +0.08~0.15em，用于 `DEFENSE SECTION` 这类注脚）。
- 数字与编号用**等宽**（`N° 008`、`C-023`、刻度）。**置信度：高**
- 中文只作为**次级注脚**出现，且字号明显小于英文标识。**置信度：中**

### 2.4 图标

- **几乎没有独立图标系统**：识别依靠「三字母代码 + 字号对比 + 色块」，而不是 icon。全片唯一稳定符号是环形徽记与仪表刻度盘。**置信度：高**（这一点直接决定了本项目的实现方式：用字体与色块承担识别，图标只做最小补充）

### 2.5 形状

- **圆角为零**。所有卡片、标签条、代码块均为直角。唯一的圆是仪表盘、显微圆形裁切与状态点。**置信度：高**
- 结构由 **1px 发丝线**定义，而不是靠阴影。**置信度：高**
- 黑标签条常带 1–2° 轻微旋转与纸张投影，形成「贴上去的纸片」感。**置信度：高**

### 2.6 阴影与质感

- 白卡是**半透明叠层**（约 6–10% 白 + 1px 浅边框 + 大范围低透明度投影），最多叠 4 层（`ui_t144.png`）。**置信度：高**
- 质感来源：纸纹、六边形底纹、黑块上的做旧划痕、扫描线。**置信度：高**

### 2.7 动效

- 以**硬切**为主，单状态停留 2–4s；没有 UI 式缓动。
- 唯一连续运动是静物的缓慢推拉与仪表指针旋转。**置信度：中**

### 2.8 信息密度

- 单一主体 + 周围 6–10 条微型标注；**空白占比高（约 55–65%）**，但标注密度高。**置信度：高**

### 2.9 语气（抽象）

- 机构档案口吻：`ANALYSIS 08`、`PERSONAL INFORMATION LOADED`、`CONFIDENTIAL`、`WARNING`。
- 句式是**名词短语 + 状态词**，不用完整句子。**置信度：高**

## 3. 五条风格公理（可执行）

1. **纸为底、墨为图**。反转只用于「分类/密级」段落，是语义，不是装饰。
2. **一个强调色，面积不超过 2%**，只标记「当前」与「信号」。
3. **让字体做工**：10 倍以上的字号落差（44px ↔ 6px）替代插图与图标。
4. **直角 + 发丝线 + 32px 网格**是结构本身；圆角仅留给点与仪表。
5. **每个主标签下配一行微型双语注脚**（中文 + 全大写英文），形成档案口吻。
